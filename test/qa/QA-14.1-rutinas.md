## Problemas y bloqueos confirmados

1. **H15 ausente:** `app/miembro/[[...seccion]]/page.tsx` usa `Pendiente`; el menú
   `Mis rutinas` en `lib/roles.ts` no es evidencia de implementación. El controlador
   `src/rutinas/controllers/rutinas.controller.ts` solo ofrece POST, GET
   `creadas-por-mi` y PUT, exclusivos para ENTRENADOR.
2. **DB-14.1 pendiente de aplicar:** bloqueo informado por el usuario. La generación
   del cliente Prisma y los builds no crean las tablas ni validan sus CHECK/FK.
3. **Defecto previo H16 fuera de estas pruebas H14:** `.env.example` define una
   base que incluye `/api/v1`; `app/actions/progreso.ts` y `app/actions/evolucion.ts`
   añaden ese prefijo otra vez. Esto bloquea preparar progreso desde la UI del
   miembro con esa configuración documentada. FE-14.2 usa el cliente compartido y
   no tiene ese defecto. No se modificó producción; para la futura QA se puede
   preparar progreso por el endpoint real de H16 con token del MIEMBRO.
4. **Mensaje previo de pagos:** el build frontend imprime `Dynamic server usage`
   para `/miembro/pagos`, pero termina con código 0. No se clasifica como build fallido.

No se detectaron nuevos defectos de producción H14 en la cobertura ejecutada.
No se infiere ausencia de errores de integración a partir de los mocks.
