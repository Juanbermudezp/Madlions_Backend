**Historia:** H22. Servicio de avisos

**Entorno:** PostgreSQL 18 del docker-compose, migraciones aplicadas y datos de `npm run db:seed`.

## Cómo ejecutarlas

```bash
npm run test:e2e
```

Los casos QA-01 a QA-18 están automatizados en [test/avisos.e2e-spec.ts](../../test/avisos.e2e-spec.ts). Usan el `AvisosService` real contra la base, con los miembros del seed, y al terminar borran los avisos que crearon (todos llevan el prefijo `[QA-22.1]` en el título).

Las reglas de la tabla (CHECK, índices, CASCADE) se prueban aparte con [DB-22.1-prueba-tabla-aviso.sql](DB-22.1-prueba-tabla-aviso.sql), y las validaciones una por una con las pruebas unitarias de `src/avisos` (`npm test`).
