La prueba e2e usa un "hoy" al azar muy en el futuro (entre 2099 y 2180) para que ninguna membresía de tu base local entre en el rango, y borra todo lo que crea (usuarios `qa24-`, planes `[QA-24.1]`, membresías y avisos).

## Ejecutar la tarea a mano

La tarea corre sola todos los días a las 06:00 (America/El_Salvador). Para correrla en el momento, sin levantar la API:

```bash
npm run build
node scripts/avisar-vencimientos.mjs              # como si fuera hoy a las 06:00
node scripts/avisar-vencimientos.mjs 2026-11-21   # como si fuera ese día a las 06:00
```

Imprime el log `Avisos de vencimiento del AAAA-MM-DD: X creado(s), Y omitido(s) por duplicado.` y los totales.

El seed de H3 ya deja los miembros que hacen falta (clave `Demo1234!`):

| Miembro                                 | Membresía del seed                                   | ¿Recibe aviso? |
| --------------------------------------- | ---------------------------------------------------- | -------------- |
| `estado.proxima@madlions.com`           | Mensual, vence en 2 días                             | Sí             |
| `estado.renovacion.pagada@madlions.com` | Mensual que vence mañana con la renovación ya pagada | No             |
| `estado.vigente@madlions.com`           | Set de clases, vence en más de 3 días                | No             |
| `estado.vencida@madlions.com`           | Mensual ya vencida                                   | No             |

Para borrar los avisos al terminar: `DELETE FROM aviso WHERE referencia LIKE 'membresia-%-vence';`
