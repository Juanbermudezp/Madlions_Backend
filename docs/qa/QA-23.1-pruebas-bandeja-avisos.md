## Datos para la revisión manual

Como ningún endpoint crea avisos, para revisar la pantalla se cargan 25 avisos no leídos a `miembro@madlions.com` directo en la base:

```sql
INSERT INTO aviso (id, miembro\\\_id, titulo, mensaje, modulo\\\_origen, creado\\\_en)
SELECT gen\\\_random\\\_uuid(), m.id,
       '\\\[QA-23.1] Aviso ' || lpad(n::text, 2, '0'),
       'Mensaje completo del aviso ' || n || ' para probar la bandeja.',
       (ARRAY\\\['MEMBRESIAS', 'CLASES', 'SESIONES', 'PAGOS'])\\\[1 + n % 4]::modulo\\\_origen,
       now() - (25 - n) \\\* interval '1 minute'
FROM miembro m
JOIN usuario u ON u.id = m.usuario\\\_id
CROSS JOIN generate\\\_series(1, 25) AS n
WHERE u.email = 'miembro@madlions.com';
```

Para borrarlos al terminar: `DELETE FROM aviso WHERE titulo LIKE '\\\[QA-23.1]%';`
