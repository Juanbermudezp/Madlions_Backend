# Madlions Gym

Plataforma web para gestionar un gimnasio: membresías y planes, reservas de clases grupales, agenda de entrenadores personales, control de acceso, pagos, rutinas y progreso, estado de las máquinas, reseñas, avisos y reportes para la administración.

**Proyecto asignado:** Proyecto 2: Plataforma de gestión de gimnasio / centro de entrenamiento
**Curso:** Ingeniería de Software, UCA, ciclo 02/2026, Sección 02

## Ambiente desplegado

| Componente | URL |
|---|---|
| Frontend | https://madlions-frontend.vercel.app |
| Documentación de la API (Swagger) | https://madlions-backend.onrender.com/api/docs |

Los usuarios de prueba se entregan en Moodle, no en este repositorio.

> El backend corre en el plan gratuito de Render y se apaga tras un rato sin uso: la primera petición puede tardar unos 50 segundos.
